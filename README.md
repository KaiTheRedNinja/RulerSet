# RulerSet
A digital set of measuring tools
## Why
I have often needed a measuring tape, without having one nearby. The built in Measure app doesn't work in tight spaces nor in low light, especially on non-Pro devices like mine.
I plan to create a measurement app that does NOT rely on the camera, and instead uses the gyroscope, accelerometer, and the screen itself to measure items.

## Feature Plan
- [ ] Simple ruler
- [ ] Simple protractor
- [ ] Simple level
- [ ] Tape measure using accelerometer
  - [ ] Measure accelerometer movement
  - [ ] Integrate accelerometer movement to obtain displacement
- [ ] Angle measurement using gyroscope
- [ ] Inches-cm-mm setting
- [ ] Skeuomorphic UI
